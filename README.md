## 🛠️ Core Competencies Demonstrated

Across the projects in this repository, you will find practical applications of:

*   **Data Engineering & ETL Pipelines:** Automating data extraction, transformation, and loading (ETL) using **Power Query** and **Python (`pandas`)** to melt wide formats, clean text anomalies, and shape raw datasets into analytics-ready structures.
*   **Relational Data Modeling & DAX:** Designing robust Star Schemas using **Power Pivot**, establishing 1:* relationships, and creating explicit analytical measures using Data Analysis Expressions (**DAX**).
*   **Exploratory Data Analysis (EDA):** Leveraging **Pandas** for vectorized data aggregations, parsing large CSV datasets, and extracting actionable business insights.
*   **Computational Mathematics & FEM:** Applying the Finite Element Method (FEM) to model deformations, performing complex matrix operations with **NumPy**, and visualizing 3D tensors using **Matplotlib**.
*   **Python Programming & OOP:** Designing modular software architecture using Object-Oriented Programming, and managing persistent application state via local **File I/O** operations.
*   **Automation & Custom Functions:** Writing **VBA** macros and Python scripts to bypass software limitations, automate repetitive workflows (e.g., Mail Merge), and encapsulate complex logic.
*   **Forecasting & What-If Analysis:** Modeling business outcomes, optimizing targets, and predicting future trends using Goal Seek, Scenario Manager, and Data Tables.
*   **Interactive Dashboards & UI:** Designing dynamic reporting tools using Pivot Tables, Slicers, and interactive **Developer Form Controls** linked with `GETPIVOTDATA`, alongside Python-based GUIs (`turtle`).
*   **Advanced Logic & Statistical Calculations:** Implementing resilient business rules (nested `IF` statements, Time Intelligence) and executing complex array/statistical calculations (`AGGREGATE`, `MODE.MULT`).
