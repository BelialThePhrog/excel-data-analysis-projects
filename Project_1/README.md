# Excel Analytics Capstone: Sales Data Analysis

## Project Overview
This project demonstrates proficiency in data cleaning, structuring, and analysis using Microsoft Excel. It highlights the ability to transform raw, unstructured datasets into a clean and actionable analytical model.

## Key Skills Demonstrated
* **Data Cleaning:** Utilized Flash Fill and text functions (`PROPER`, `TRIM`, `CLEAN`) to standardize input data.
* **Data Structuring:** Converted raw datasets into professional Excel Tables (`Tbl_Transactions`, `Tbl_Catalog`) and implemented Named Ranges for better formula management.
* **VLOOKUP & Error Handling:** Performed cross-sheet data integration with robust error handling using `IFNA` and `IFERROR`.
* **Logical Functions:** Applied nested `IF` statements and absolute referencing to automate business logic and commission calculations.
* **Reporting:** Leveraged `SUBTOTAL` functions to create dynamic, region-based sales summaries.

## How to Use
1. Download the `Project_1.xlsx` file.
2. The "Raw_Transactions" sheet serves as the primary data input.
3. The "Dashboard" sheet contains the automated calculations and reporting analysis.
